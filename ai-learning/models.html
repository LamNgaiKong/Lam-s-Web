    板块三：AI 名词释义 概念词典

    名词释义通俗类比工程/AI 场景说明
    提示词
    （Prompt）    		 用户输入给模型的指令性文本，是引导模型输出行为与内容格式的"输入接口" 给新入职员工的任务说明书：写清楚目标、约束和验收标准，干出来的活才靠谱 工程上分系统提示词（System Prompt，定人设与规则）与用户提示词；提示工程（Prompt Engineering）研究如何用措辞、示例（Few-shot）、角色设定提升输出质量；是 Agent 工具调用的入口
    上下文
    （Context）    		 模型在当前请求中"可见"的全部信息：系统提示 + 历史对话 + 检索到的资料 + 工具返回结果等 会议室里所有与会者手头的资料和会议纪要：桌上有什么，大家就只能基于什么讨论 受上下文窗口（Context Window，以 Token 计）硬限制；"上下文工程"（如 RAG 检索增强、上下文压缩、Qoder 的 Repo Wiki 增强上下文）决定 Agent 能否"看见"足够多的代码；上下文污染/超长会导致模型"遗忘"或答非所问
    基座
    （Base Model）    		 经大规模预训练得到的基础大模型，是上层一切能力（微调、对齐、应用）的"底座"；产品语境下也泛指某应用底层实际调用的原生模型 汽车发动机：整车厂（应用产品）可以不自造发动机，直接采购现成发动机（基座）装车 狭义指未做指令微调/RLHF 的预训练模型（base model），与 Instruct/Chat 版本相对；工程选型时须区分"自研基座"与"调用他人基座"（如 Cursor 调用 Claude、WorkBuddy 调用混元），这直接决定成本结构、数据主权与能力天花板

    核心定义

    什么是物理 AI

    核心定义：物理 AI（Physical AI）指能够理解、推理并与真实物理世界交互的 AI 系统，典型载体是机器人、自动驾驶汽车与各类自主机器。它把大模型的语言/视觉智能与真实世界的感知、动力学和操控能力结合，形成"感知 → 推理 → 规划 → 动作"的闭环。

    核心目标：让智能体在真实物理世界中完成理解（感知场景与物体）、交互（灵巧操作、触觉反馈）与控制（全身运动、力控）——覆盖机器人操作（Manipulation）、触觉感知、动力学建模，以及从仿真到现实的迁移（Sim2Real）。

    与纯文本大模型的区别

    纯文本大模型在 Token 空间里"说"，物理 AI 在真实世界里"做"：输出从文本变为连续的动作/关节指令；必须处理真实物理约束（重力、接触、摩擦、延迟）；错误不再是"答错"，而是现实中的碰撞与损坏；数据从互联网文本变为真机演示、遥操作与仿真数据；评估从基准分数变为真实任务成功率。

    关键技术栈

    仿真环境

    Isaac Sim / Isaac Lab、MuJoCo、SAPIEN、Genesis 等，在虚拟世界低成本试错并生成海量训练数据。

    动作策略

    端到端视觉-语言-动作（VLA）模型、扩散策略（Diffusion Policy）、全身控制策略，直接输出关节/末端指令。

    模仿学习

    从人类演示/遥操作数据做行为克隆（BC、ACT、robomimic 等），是当前真机数据利用的主流范式。

    强化学习

    PPO、AMP 等在仿真中大规模试错；SuperMimic 等进一步用可微世界模型 + BPTT 提升样本效率。

    视觉-触觉多模态

    融合相机、深度、力/触觉传感器信号，支撑精细灵巧操作。

    动力学建模

    刚体/软体动力学、接触模型与可微物理；世界模型学习环境动力学用于规划与训练。

    域自适应 / Sim2Real

    域随机化、系统辨识、动力学在线校准，缩小仿真与真机之间的分布差距。

    轨迹优化

    MPC、iLQR/DDP、全身运动规划，生成可行且最优的参考轨迹与接触序列。

    SuperMimic 详解

    项目介绍

    SuperMimic（CoRL 2026，arXiv:2610.28480，论文标题 "Scaling Humanoid Whole-Body Control with One Differentiable World Model"），由伯克利团队（Qiayuan Liao 等）提出：用单个可微世界模型 + 单张 H100 GPU 即可训练人形机器人全身控制策略。同名区分 注意与 arXiv:2509.22205 的 Super-Mimic（基于人类视频的长程操作分层模仿框架）不是同一工作。

    核心思路：如何利用人类演示与姿态/轨迹模仿

    SuperMimic 做的是目标条件下的全身动作模仿：给定一段由人体动作捕捉（mocap）或动作库提供的参考轨迹，策略需要驱动人形机器人复现对应的全身姿态与运动。它并非"看视频直接学"，而是先在仿真中训练一个可微世界模型近似机器人动力学，再让策略沿参考轨迹在该模型中"试错"——以短时域 BPTT（时间反向传播）训练 Actor-Critic，策略输出各关节设定点（joint setpoints）逐段跟踪参考姿态，实现姿态/轨迹级模仿。同一世界模型还可复用：直接以任务奖励用 RL 优化目标编码器。

    如何打通仿真与真机（Sim2Real）

    训练全程在仿真中进行：在真实仿真器中持续采样、迭代更新可微动力学模型，使世界模型与仿真环境互相对齐；部署时把策略输出的关节目标交给低刚度 PD 控制器执行——低增益控制器天然容忍模型误差，吸收仿真与真机的动力学残差，从而实现从仿真到 Unitree G1 真机的直接迁移，无需真机大规模微调。

    能力与擅长任务

    擅长全身动态运动类任务：翻滚、跳跃、全身协调动作，以及需要全身参与的动态操作（而非桌面双臂精细抓取）。核心能力：目标条件全身模仿、单卡高效训练、世界模型复用。

    数据集 / 优缺点 / 最新进展

    数据集：参考轨迹来自人体动作捕捉与动作库（BONES-SEED 数据）。

    优点：训练效率极高（单 H100 可扩展全身控制）；世界模型可复用于 RL 目标优化；Sim2Real 迁移简洁（低刚度 PD 兜底）。

    缺点：代码未完全开源；当前验证集中于 Unitree G1 真机；策略上限受世界模型精度制约。

    最新进展：CoRL 2026 接收（2026-10 公布），引发"单卡训练人形机器人"讨论；后续工作（如 arXiv:2610.41654）延续可微世界模型路线。

    代表性项目 / 团队

    RoboTwin 2.0（港中大（深圳）李镇团队，ICML 2026）

    开源双臂操作数据生成器与基准：以强域随机化规模化合成可迁移到真机的操作数据，并构建评测基准；对比 π0、OpenVLA-OFT 等基线，推动 VLA 模型的标准化评测。

    DexMV（ECCV 2022，多指灵巧手）

    从人类手部视频学习灵巧操作的模仿学习框架：构建视频-仿真配对数据，将人手运动重定向（retargeting）到多指灵巧手，解决灵巧操作数据采集难的问题，是"人类演示 → 灵巧手"路线的早期代表。

    OpenVLA / OpenVLA-OFT（斯坦福、伯克利等）

    开源 7B 视觉-语言-动作（VLA）模型，在 Open X-Embodiment 大规模真实机器人数据集上训练，支持 LoRA 等低成本微调，是当前开源机器人策略的事实基准之一。

    Google Robotics / Google DeepMind Robotics

    RT-1 → RT-2（VLM 直接输出机器人动作，把网络知识迁移到未见指令）→ Gemini Robotics（2025）→ Gemini Robotics 2（2026-07-30：全身智能、灵巧操作、多机器人协同）与 Gemini Robotics ER 2（具身推理：视频理解、工具编排、多机器人协作），代表"大模型 → 具身"的工程化路线。

    NVIDIA（平台 / 生态）

    Isaac 仿真框架 + Cosmos 3 世界基础模型（统一合成世界生成、视觉推理与动作模拟）+ Isaac GR00T N1.7（2026-03 开放抢先体验与商业授权，主打通用机器人技能与灵巧控制），定位物理 AI 的基础设施。

    当前发展现状、瓶颈、落地方向与未来路线

    发展现状（截至 2026-11）

    世界模型成为新焦点（Cosmos 3 统一生成/推理/动作模拟）；VLA 与全身控制旗舰落地（Gemini Robotics 2）；训练成本大幅下降（SuperMimic 单卡训人形全身控制）；开源生态成熟（RoboTwin 2.0、OpenVLA、LeRobot）；人形机器人进入"量产就绪"阶段（GR00T N1.7 开放商业授权）。

    主要瓶颈

    ① 真实数据稀缺且昂贵（如 EgoSmith 数据管线 9.6K 小时规模，其世界模型增强 VLA 在 40+ 任务上成功率约 75%，与人类仍有差距）；② Sim2Real 差距尚未根治（域随机化只是缓解）；③ 长程、接触密集任务成功率低；④ 全身灵巧操作受硬件自由度与触觉传感器限制；⑤ 评测基准与指标不统一。

    落地方向

    制造业分拣与装配、仓储物流（双臂/人形）、服务与家庭机器人、多机器人协作（ER 2 方向）、自动驾驶与自主机器（广义物理 AI）。

    未来路线

    世界模型 + 合成数据闭环突破数据墙；端到端 VLA 规模化；从桌面操作走向全身灵巧控制；具身推理（ER）从研究转向工程化；开源权重与商业授权并行，加速量产落地。
